# itsbrianlou.com

Brian Lou 的個人首頁，一頁純靜態網頁（HTML + CSS），不需要任何框架或 build。
用來示範：把架在 GitHub Pages 或 Vercel 上的網站接上自己的網域。

## 部署

**GitHub Pages**

1. 把這個 repo push 到 GitHub。
2. Settings → Pages → Source 選 **Deploy from a branch** → Branch 選 `main`、資料夾選 `/ (root)` → Save。

**Vercel**

1. 在 Vercel 點 **Add New → Project**，Import 這個 repo。
2. Framework Preset 選 **Other**，其他不用設定，直接 Deploy。
